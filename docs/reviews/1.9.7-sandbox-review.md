Date: 2026-11-23. Gate 1; threat 4 (sandbox escape) and the threats around it.
Status: **filed. No critical finding. Nine findings: one did not hold, eight are fixed.
The fixes have not been reviewed by the second family.**

## How it was done

- **Reviewer:** GPT-6.2 Astra (OpenAI). The code was written by Claude (Anthropic).
- **Given:** the threat table (`docs/decisions/0.1.10-threat-scores.md`), the limits
  record, and the source of the sandbox, the static check, the broker and the code tool:
  15 files. Not given: the audit log, the registry, the connector, the release gate, the
  tests.
- **Asked for:** flaws the author missed, as structured findings with a proof and a fix.
- One call, `scripts/sandbox-review.ts`. Its reply is in `1.9.7-sandbox-review.json`,
  unedited. Cost: $0.36 of the $2 the project owner approved.

Each finding was then checked against the code by the author before anything was
changed. That check is the author judging findings about its own work.

## Findings

| # | Severity given | Finding | Verdict | What was done |
|---|---|---|---|---|
| F1 | High | A script refused for holding a secret is written to the audit log with the secret in it | **Does not hold.** The audit log removes anything matching the same secret patterns before writing. The reviewer was not shown that code | A test now proves it |
| F2 | High | A call still being checked when its run ends can be sent upstream afterwards | Holds | The broker checks again just before sending and before handing a result back. The executor tells the broker when a run is over |
| F3 | High | Logs and the result are cut to size only after they were built and sent to the host | Holds | The code beside the script stops collecting logs at the budget and cuts the result before sending. The host still cuts what arrives |
| F4 | High | A failing tool's error text reaches the script without being counted as data | Holds | A sensitive tool's words are withheld: the script is told it failed and the status code. Any other tool's words count as a read of its data class |
| F5 | Medium | Whether a value is checked as a URL depends on the order of a schema's branches | Holds. No tool has such a schema today | URLs and paths are collected from every branch the value fits |
| F6 | Medium | The script runs even if a global could not be hidden | Holds. It has not happened on Cloudflare | The script is not run, and the host treats the run as a fault. The check now also looks for the name left on a prototype |
| F7 | Medium | A sandbox fault's message can carry text from outside | Holds | The caller gets fixed words. What the platform said goes to the audit log |
| F8 | Medium | A run whose result is withheld still reports how many assertions passed | Holds | The count is reported as zero and kept in the audit log |
| F9 | Medium | One search can buy any amount of host work | Holds. Made worse the same day by the search ranking | A search is at most 500 characters and 16 words; a name at most 200 characters. Checked where the call enters the host |

## Evidence

- `test/review-findings.test.ts`: 11 tests when filed (13 since), one or more per finding except F3.
- F3 and F6 are in the code that runs inside the sandbox. The local-runtime tests and
  the 28 tests on Cloudflare pass with it, which shows nothing broke and that no global
  is left on the deployed runtime. That the excess is no longer sent is by reading the
  code, not by a test.
- All 810 local tests pass. Nine eval tasks per model were rerun through Code Mode
  after the fixes: 18 of 18 correct.

## What the reviewer found sound

Default deny for a missing or unusable policy record; no property-name trick that turns
a missing record into permission; the isolate has no network, an empty environment and
no Node compatibility; no path where a failed script is run in the host; the result
block's delimiters cannot be forged from inside.

## Limits

- **The fixes were not reviewed by the second family.** One pass was approved.
- **Left open by F8:** a withheld run still reports how many calls it made and how long
  it took. A script can vary both. Closing that means reporting nothing about a
  withheld run.
- **Left open by F4:** for a tool not marked sensitive, up to 500 characters of the
  upstream's error still reach the script. They are now counted, not removed.
- **Left open by F3:** a script can still build a large value inside its own memory
  limit. Tool arguments have no size limit of their own where they enter the host.
- **Not reviewable from the source given**, in the reviewer's words: Cloudflare's own
  isolation and transport limits; how production binds a project to a signed-in caller;
  the pinning of definitions; the connector's handling of its credential; audit-log
  access and retention; the release gate; the supply chain. Each is covered elsewhere
  or is still to be built, and none was examined here.
- A model's review is not a penetration test (task G.10).
- The eval figures in `docs/research/1.9.5-code-arm-report.md` were measured before
  these fixes. Only the nine-task check was rerun after them.
