## What the sign-off does not claim

The owner signed off with these stated:

- **Nothing is defended yet.** The adversarial suite passes against a stub with no
  defences. That shows the suite can detect an open attack. The first run that means
  anything for safety is against the Phase 1 server, before Gate 1.
- **The baseline is narrow.** Two small models, invented data that answers instantly, 30
  tasks. The comparison points have to be re-measured if other models become targets.
- **The threat scores are judgments.** Claude proposed them and the owner accepted them.
  No outside reviewer has seen them. A second model family reviews the sandbox before
  Gate 1 (task 1.9.7); a paid human review comes before real client data or writes (G.10).
- **The name is cleared at first pass only.** No legal opinion, EU and international
  registers not searched, and `execward.com` is chosen but not yet bought.
